## Engineering Principles

I care about:

* **Correctness before cleverness**
* **Understanding before abstraction**
* **Simple designs before unnecessary complexity**
* **Security as part of the design**
* **Tests as evidence, not decoration**
* **Measuring performance instead of guessing**
* **Documenting trade-offs and failures**
* **Building systems that can actually be operated**
